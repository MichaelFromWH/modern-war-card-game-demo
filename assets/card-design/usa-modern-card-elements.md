# 美军现代单位牌设计元素 V2

本轮将卡牌拆成两层：插画资产层负责 2:3 写实战场画面，前端 UI 层统一叠加名称、战力、标签、技能、稀有度和阵营标识。

## 插画层

- 目录：`assets/card-art-v2/`
- 比例：`2:3`
- 标准尺寸：`1024 x 1536`
- 内容约束：不包含卡牌边框、名称、战力、技能文字、星级或阵营徽记。
- 使用方式：美军单位牌优先读取 `assets/card-art-v2/<art>.jpg`，非现代单位牌继续读取旧目录 `assets/card-art/`。

## UI 层

- 单位名称：顶部详细牌展示，简版手牌/场上牌在底部展示。
- 战力值：1-8 由数据驱动，使用雷达圆环战力徽章，不再单独生成数值图片。
- 部署区域：详细牌仅展示 `前线` / `支援` 等部署区域，不展示 `单位牌`。
- 单位标签：详细牌展示主标签，例如 `步兵`、`装甲`、`直升机`。
- 技能图标：由技能关键词映射到统一符号，规则在 `src/card-design.js`。
- 技能面板：仅详细牌展示，保证完整文本可读；简版隐藏技能。
- 稀有度：1-5 星由 `rarity` 映射，不单独绑定具体卡名。
- 阵营图标：美军统一使用右下角星徽，避免不同卡牌徽记不一致。

## 变体

- 简版：用于手牌和场上，只保留插画、战力值、名称。
- 详细版：用于 hover 预览和牌库详情，展示完整机制文本和全部设计元素。
