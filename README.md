# 现代战争双层战场卡牌 WebDemo

基于 V0.8 核心机制与美俄首发卡组/组卡规则的可玩原型：三线战场、通用隐蔽部署、前线接敌/伏击、前线突破、50 点摧毁得分胜利、补给耗尽最终行动、24 张驻场单位 + 6 张功能战术牌。单位牌均为驻场牌，并拆分为攻击、生命和目标价值；巡航导弹、弹道导弹、SEAD 战斗机和轰炸机也拥有生命并可被摧毁得分。巡航导弹仅能打击暴露地面目标或直升机，可被伴随/重型防空拦截；弹道导弹打击规则相同，但只能被重型防空拦截；SEAD 可指定隐蔽防空单位，若目标仍有拦截窗口，打击被抵消为暴露目标并消耗该窗口。鼠标悬停卡牌时会在放大卡牌侧边显示单位属性、攻击/生命/价值与特殊规则注释。

## 本地运行

```bash
npm run dev
```

默认地址为 `http://localhost:3000`。如果端口占用，可以使用：

```bash
PORT=3001 npm run dev
```

## GitHub Pages

仓库可通过 GitHub Pages 从 `main` 分支根目录直接发布为静态页面。
