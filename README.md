# 现代战争双层战场卡牌 WebDemo

基于 V0.4.1 核心机制与美俄首发卡组/组卡规则的可玩原型：三线战场、通用隐蔽部署、前线接敌/伏击、前线突破、50 点摧毁得分胜利、补给耗尽最终行动、24 张驻场单位 + 6 张功能战术牌。巡航导弹、弹道导弹、SEAD 战斗机和轰炸机为驻场单位，拥有战力并可被摧毁得分；伴随防空可拦截巡航导弹，弹道导弹与 SEAD 反辐射导弹只能被重型防空拦截。

## 本地运行

```bash
npm run dev
```

默认地址为 `http://localhost:3000`。如果端口占用，可以使用：

```bash
PORT=3001 npm run dev
```

## GitHub Pages

仓库可通过 GitHub Pages 从 `main` 分支根目录直接发布为静态页面。
